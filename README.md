# יומן מסע — פורטוגל וספרד (אוגוסט 2026)

מסמך HTML יחיד (RTL, עברית) עם המסלול המלא: 3 לילות בליסבון, קרוז Norwegian Dawn מליסבון לברצלונה, ולילה בברצלונה. כולל שעות נמל, ארוחות, הסעות, מלונות, אלמנטים יהודיים, קניות וקישורים חיים.

## קבצים
| קובץ | תיאור |
|---|---|
| `index.html` | המסמך — זה שמתפרסם ב-GitHub Pages |
| `CLAUDE.md` | הקשר ומשימות ל-Claude Code |

> **פרטיות:** המסמך נוקה מפרטים רגישים (קודי הזמנה, מחירים, שמות משפחה מלאים, טלפונים, מספרי טיסה). נשמרים רק פרטים לא רגישים כמו תאריכי ביטול חינם ושמות מלונות.

---

## פרסום ב-GitHub Pages (גישה פתוחה לכולם)

1. **Settings → Pages → Source: Deploy from a branch**.
2. בחר את הברנץ׳ שבו נמצא `index.html` ותיקייה `/ (root)` → **Save**.
3. אחרי דקה-שתיים האתר יהיה זמין בכתובת:
   `https://yarivg.github.io/cruise-2026/`

---

## עריכה מרחוק עם Claude Code

1. פתח את הריפו ב-**Claude Code** (מהדפדפן, אפליקציית הדסקטופ, או הנייד).
2. Claude Code יטען אוטומטית את `CLAUDE.md` כהקשר הפרויקט.
3. בקש עריכות בשפה חופשית, למשל:
   - "מלא את שם המסעדה ליום 8.8"
   - "סמן את סירת בנאגיל כמוזמנת"
   - "עדכן את שעת ההסעה ב-9.8"
4. Claude יערוך, יעשה `commit` ו-`push`, ו-GitHub Pages יתעדכן אוטומטית תוך דקה.
